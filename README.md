# ⚓ Ναυμαχία

Ναυμαχία για 2 παίκτες σε Python/pygame. Κάθε παίκτης παίζει από τη δική του συσκευή (PC ή tablet) στο ίδιο Wi-Fi. Υπάρχει και παιχνίδι με τον υπολογιστή.

## Τι έχει
- Σχεδιασμένα πλοία: Αεροπλανοφόρο, Θωρηκτό, Καταδρομικό, Υποβρύχιο, Αντιτορπιλικό
- Ειδικές δυνάμεις:
  - ✈ **Αεροπορική επιδρομή** (Αεροπλανοφόρο): 3 βόμβες στη σειρά, ×2
  - ◉ **Σόναρ** (Υποβρύχιο): εντοπίζει πλοία σε 3×3, ×2
  - ✚ **Ομοβροντία** (Θωρηκτό): 5 βολές σε σταυρό, ×1
  - Αν βυθιστεί το πλοίο, χάνεται και η δύναμή του.
- Εκρήξεις, φωτιές, καπνός, στερεοφωνικοί ήχοι, chat, ρεβάνς

## Παιχνίδι στον υπολογιστή
```
pip install pygame
python main.py
```

## Παιχνίδι στο tablet (Android)
1. Ανέβασε όλα τα αρχεία αυτού του φακέλου σε ένα repo στο GitHub, στο branch `main`.
2. Το GitHub φτιάχνει μόνο του το APK. Η πρόοδος φαίνεται στην καρτέλα **Actions**. Η πρώτη φορά κρατάει περίπου 20–30 λεπτά, οι επόμενες είναι πιο γρήγορες.
3. Όταν τελειώσει, άνοιξε από το tablet τη σελίδα **Releases** του repo και πάτα το αρχείο `Naumaxia-v1.X.apk`.
4. Την πρώτη φορά το Android θα ζητήσει άδεια για «εγκατάσταση άγνωστων εφαρμογών» από τον browser. Πάτα «Να επιτρέπεται».

Κάθε νέα αλλαγή που ανεβαίνει στο `main` φτιάχνει αυτόματα καινούργιο APK.

## Πώς παίζεται στο tablet
- **Τοποθέτηση:** πάτα στο ταμπλό για να βάλεις το πλοίο. Υπάρχουν κουμπιά για Περιστροφή, Τυχαία, Αναίρεση και Καθαρισμό.
- **Βολή:** πάτα μία φορά για να σημαδέψεις (φαίνεται ο στόχος) και **ξανά στο ίδιο σημείο για φωτιά**.
- **Αεροπορική επιδρομή:** πάτα ξανά το κουμπί της για να γυρίσει οριζόντια ή κάθετα.
- **Chat:** πάτα στο κουτάκι του chat και ανοίγει το πληκτρολόγιο.
- **Ήχος:** πάτα στη γραμμή «Ήχος» στο μεσαίο πάνελ.

## 2 παίκτες
Και οι δύο συσκευές πρέπει να είναι **στο ίδιο Wi-Fi**.
- Ο ένας πατάει **«Δημιουργία παιχνιδιού»** και βλέπει την IP του.
- Ο άλλος πατάει **«Σύνδεση σε παιχνίδι»** και γράφει αυτή την IP.

Παίζει και PC με tablet. Στα Windows, την πρώτη φορά, πάτα «Allow» στο μήνυμα του Firewall.

| `buildozer.spec` | Ρυθμίσεις για το APK |
| `.github/workflows/build-apk.yml` | Το αυτόματο build στο GitHub |
